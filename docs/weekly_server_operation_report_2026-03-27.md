## 2. 상세 운영 지표

*   **사용자당 몰입도 증가:** 전체 트래픽은 줄었지만 방문자 1인당 평균 TTS 호출 수는 증가했습니다. 이는 서비스를 처음 접하는 사람보다 꾸준히 이용하는 시각 장애인 사용자층의 활동이 더 활발했음을 의미합니다.
