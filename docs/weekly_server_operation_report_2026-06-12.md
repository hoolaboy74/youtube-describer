## 2. 상세 운영 지표

### 2.1 트래픽 및 사용자 활동
*   **수요의 급증:** 고유 방문자 수가 1,675명으로 늘어나며 신규 트래픽 유입이 활발했습니다. 이에 따라 영상 생성 시도 역시 105건으로 전주 대비 81.0% 급증하였습니다.
*   **TTS 호출의 폭증:** 해설 영상 감상 수의 증가로 인해 TTS API 호출 건수가 4,104건으로 약 2배 가까이 폭증하여, 캐싱 서버 부하 관리가 필요한 상태입니다.

### 2.2 영상 처리 및 비용 효율
*   **성공률 폭락 원인 분석 (총 41건의 실질적 실패):**
