<유튜브 화면해설 자동 생성기 개발 계획안 (상세 버전)>

I. 개요

*   주제: AI를 활용하여 시각장애인을 위한 유튜브 화면해설을 자동으로 생성하고, 이를 통해 미디어 접근성의 혁신을 이룸.
*   기획 및 개발자: 차주현 (시각장애인 MOM 센터 운영위원)
*   핵심 기술:
    *   AI 모델: Google의 최신 멀티모달 AI 모델인 gemini-2.5-pro를 활용. 영상의 모든 핵심 프레임과 유튜브 자동 생성 자막 전체를 한 번에 분석하여, 영상의 서사적 맥락을 완벽하게 이해한 상태에서 일관성 높은 화면 해설 스크립트를 생성함.
    *   음성 합성: Google Cloud Text-to-Speech (TTS) API를 통해 사람의 목소리와 유사한 자연스러운 고품질의 한국어 해설 음성을 생성함.
    *   개발 환경: 백엔드는 Node.js (Express.js), 프론트엔드는 React를 기반으로 개발되었으며, 시각장애인 사용자를 위한 웹 접근성 표준(WCAG)을 철저히 준수함.
*   트라이얼 버전 개발 기간: 2025년 9월 ~ 11월
*   사용 대상자: 모든 시각장애인 유튜브 시청자 및 미디어 접근성에 관심 있는 사용자.

II. 배경

*   현대 사회에서 정보와 문화 향유의 중심축은 OTT, 유튜브 등 디지털 미디어로 빠르게 이동하고 있음.
*   특히 유튜브는 단순한 영상 소비를 넘어, 댓글 등을 통한 적극적 참여가 보장되는 양방향 소통 플랫폼으로 자리 잡았으며, 모든 시민의 일상에 필수적인 매체가 되었음.
*   그러나 기존의 화면해설 서비스는 영화, TV 방송 등 전통 미디어에 집중되어 있어, 방대한 양의 콘텐츠를 보유한 유튜브는 사실상 시각장애인의 접근이 불가능한 '정보의 섬'으로 남아있는 실정임.
*   이로 인해 시각장애인의 유튜브 화면해설 서비스에 대한 사회적 요구가 매우 높음.
*   최근 AI 기술의 혁신적 발전은 시각장애인의 삶에 큰 변화를 가져오고 있으며, 본 프로젝트는 이러한 기술을 활용하여 미디어 소비의 불평등을 해소하는 것을 목표로 함.

III. 목표

*   자동화된 해설 생성: AI 기술을 활용하여 모든 유튜브 영상에 대한 화면해설을 자동으로 생성하는 서비스를 개발함.
*   사용자 주도적 콘텐츠 감상: 시각장애인 사용자가 직접 원하는 유튜브 콘텐츠의 화면해설을 생성하고, 해설의 상세 수준을 '없음/최소/기본/최대' 4단계로 직접 조절하며 주도적으로 감상할 수 있는 환경을 제공함.
*   자원의 공유 및 효율성 증대: 한 사용자가 생성한 화면 해설 데이터(텍스트 스크립트 및 음성 파일)는 서버 데이터베이스에 영구적으로 저장됨. 이를 통해 다른 사용자가 동일 영상을 시청할 경우, 기다림 없이 즉시 해설을 이용할 수 있어 자원 활용의 효율성을 극대화함.
*   최고 수준의 접근성 확보: 개발 초기 단계부터 스크린리더 사용자를 포함한 모든 시각장애인의 사용성을 최우선으로 고려하여, 직관적이고 안정적인 사용자 인터페이스(UI)를 설계하고 구현함.

IV. 프로그램 개발 및 핵심 기능

1. 사용자 중심의 UI/UX 설계
*   통합 검색 인터페이스: 첫 화면에서 URL을 직접 입력하여 새 해설을 생성하거나, 키워드를 입력하여 로컬 데이터베이스와 유튜브에서 동시에 영상을 검색하는 통합 검색 기능을 제공함.
*   접근성이 강화된 플레이어: 유튜브의 기본 컨트롤을 숨기고, 중앙의 큰 재생/일시정지 버튼 등 필수 기능만으로 구성된 간소화된 플레이어를 제공하여 조작의 복잡성을 최소화함.
*   반응형 디자인: 모바일과 PC 등 모든 기기에서 최적의 사용 경험을 제공하는 반응형 웹 디자인을 적용함.
*   사용자 소통 기능: 영상 하단에 닉네임과 비밀번호 기반의 댓글 기능을 구현하여 사용자들이 의견을 교환하고 피드백을 제공할 수 있는 창구를 마련함.

2. 고성능 백엔드 아키텍처
*   점진적 데이터 처리 (Progressive Processing & SSE): 사용자의 대기 시간을 최소화하기 위해, 해설 생성 요청 시 AI가 생성하는 스크립트를 실시간 스트리밍(SSE) 방식으로 프론트엔드에 전송함. 사용자는 전체 프로세스가 끝나기를 기다릴 필요 없이, 생성되는 부분부터 즉시 읽고 들을 수 있음.
*   하이브리드 TTS 캐싱 (Hybrid TTS Caching): API 비용 최적화 및 응답 속도 극대화를 위해 독자적인 캐싱 시스템을 구축함.
    *   해설 텍스트의 고유 해시(SHA256) 값을 파일명으로 사용하여 오디오 파일을 서버에 영구 저장.
    *   반복 요청 시 TTS API를 재호출하는 대신, 100% 캐시된 파일을 즉시 제공하여 비용을 획기적으로 절감하고 응답 속도를 밀리초(ms) 단위로 단축함.
    *   주기적으로 오래된 캐시를 자동 삭제하는 기능을 포함하여 저장 공간을 효율적으로 관리함.

3. AI 및 핵심 기술 상세
*   AI 기반 해설 생성:
    *   Google gemini-2.5-pro: `yt-dlp`와 `ffmpeg`을 이용해 추출한 영상의 모든 핵심 프레임과 유튜브 자동 생성 자막 전체를 AI 모델에 단일 컨텍스트로 제공. 이를 통해 AI가 영상의 전체적인 서사와 등장인물의 대화 흐름까지 완벽하게 파악하여, 단편적인 장면 묘사를 넘어 맥락의 일관성이 유지되는 고품질 해설을 생성함.
*   핵심 개발 기술:
    *   백엔드: Node.js, Express.js
    *   프론트엔드: React (Create React App)
    *   영상/자막 처리: `yt-dlp`, `fluent-ffmpeg` 등 검증된 오픈소스 라이브러리
    *   데이터베이스: SQLite (`better-sqlite3`)를 사용하여 생성된 스크립트, 영상 메타데이터, 사용자 댓글 등을 효율적으로 관리함.

4. 개발 및 배포 과정
*   1단계 (요구사항 분석 및 설계): 시각장애인 커뮤니티의 의견을 수렴하여 핵심 기능을 정의하고, 위에 명시된 아키텍처를 설계함.
*   2단계 (프로토타입 개발): 설계된 아키텍처를 바탕으로 실제 작동하는 트라이얼 버전을 개발. 수십 차례의 기능 개선 및 버그 수정을 통해 안정성을 확보함 (상세 내용은 `GEMINI.md`의 '개선 기록' 참고).
*   3단계 (사용자 테스트 및 피드백 반영): 시각장애인 MOM 센터 회원을 대상으로 심층 사용성 테스트를 진행하고, 발견된 오류 수정 및 개선점을 반영함.
*   4단계 (출시 및 홍보): 서비스 안정성을 최종 점검한 후, 시각장애인 온라인 커뮤니티 등을 통해 공식적으로 출시하고 홍보함.

V. 기대효과

*   정보 접근성 장벽 해소: 현대 미디어 소비의 중심인 유튜브 활용에 있어 시각장애인이 겪는 정보 격차를 근본적으로 해소함.
*   미디어 소비의 주체성 강화: 시혜적인 복지 서비스의 수혜자가 아닌, 원하는 콘텐츠를 직접 선택하고 소비하는 능동적인 미디어 소비자로서의 시각장애인 위상을 정립함.
*   개인 맞춤형 콘텐츠 소비 실현: 기존 방송 화면해설과 달리, 개인의 관심사와 필요에 맞는 유튜브 콘텐츠를 100% 자유롭게 선택하여 감상할 수 있음.
*   혁신적인 비용 효율성: 하이브리드 TTS 캐싱 기술을 통해 한 번 생성된 음성 해설 자원을 모든 사용자가 공유하므로, 반복적인 API 호출 비용이 발생하지 않음. 이는 기존의 고비용 화면해설 제작 방식과 비교할 수 없는 수준의 경제적 효율성을 제공하며, 서비스의 지속 가능성을 담보함.

VI. 한계 및 발전 방향

*   품질의 한계: AI가 생성하는 해설은 사람이 직접 제작하는 수준의 감성적 뉘앙스나 복잡한 은유를 완벽히 표현하기에는 아직 기술적 한계가 존재함. 하지만 본 서비스는 영상 전체의 맥락과 자막을 AI에 통합 제공하는 방식으로, 기존의 단편적인 이미지 분석 기술보다 월등히 높은 수준의 정확성과 일관성을 확보했음.
*   운영 비용: 서비스 사용량이 증가할수록 서버 유지 및 초기 API 호출에 따른 최소한의 운영비가 발생할 수 있음.
*   향후 발전 방향: 사용자들이 AI가 생성한 해설을 직접 수정하고 개선하는 '커뮤니티 편집(위키)' 기능, 선호하는 음성을 선택하는 'TTS 음성 선택' 기능 등을 도입하여 지속적으로 서비스를 고도화할 계획임.

VII. 예산

*   개발 비용: 시각장애인 MOM 센터 운영위원인 차주현의 재능 기부로 전액 충당됨.
*   운영 비용: 출시 초기 운영비는 시각장애인 MOM 센터의 후원금과 사용자들의 자발적인 후원으로 충당할 계획임.
*   중장기 계획: 서비스가 활성화되면, 공공 및 민간 기업의 사회공헌 프로젝트 지원금을 유치하여 안정적인 운영 재원을 확보하고 서비스를 고도화해 나갈 예정임.
