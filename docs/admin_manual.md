# 뷰레이터(Vureater) 서비스 관리자 매뉴얼

## 1. 개요

이 문서는 뷰레이터 서비스의 핵심 기능을 관리하고 서비스의 정책과 상태를 제어하는 관리자 페이지의 사용 방법을 안내합니다. 관리자 페이지의 각 기능은 서비스의 안정성, 재정 상태, 사용자 경험에 직접적인 영향을 미치므로, 각 항목의 의미를 정확히 숙지하고 신중하게 사용해야 합니다.

## 2. 접속 및 인증

- **접속 방법**: 서비스 URL 뒤에 `/admin` 경로를 추가하여 접속할 수 있습니다. (예: `https://www.blindmom.org/admin`)
-   **인증**: 접속 시 비밀번호를 요구합니다. 사전에 공유된 관리자용 비밀번호를 입력해야만 기능에 접근할 수 있습니다.

## 3. 주요 기능 상세

관리자 페이지는 **대시보드, 콘텐츠 관리, 비용 관리, 서비스 설정**의 네 가지 주요 탭으로 구성되어 있습니다.

---

### 3.1. 대시보드

대시보드는 서비스의 현재 상태를 한눈에 파악할 수 있는 종합 현황판입니다.

| 카드 이름 | 설명 | 사용자에게 미치는 영향 |
| :--- | :--- | :--- |
| **재정 요약** | 총 후원금, 총 API 사용 비용(USD), 그리고 설정된 환율을 기반으로 계산된 원화 잔액을 표시합니다. | 잔액이 0 이하가 되면 **신규 영상 해설 생성이 중단**됩니다. 서비스의 지속 가능성을 판단하는 가장 중요한 지표입니다. |
| **API 비용 요약** | 오늘, 최근 7일, 최근 30일간 발생한 API 비용을 원화로 환산하여 보여줍니다. | 비용 추이를 통해 특정 기간에 API 사용량이 급증하지 않았는지 확인할 수 있으며, 이는 비용 관리 정책 수립의 근거가 됩니다. |
| **핵심 통계** | 총 생성된 영상 및 댓글 수, 기간별(오늘, 주, 월) 처리된 영상 수를 보여줍니다. | 서비스의 전반적인 활성도를 나타냅니다. |
| **시스템 상태** | 현재 '처리 중'이거나 최근 24시간 내 '실패'한 영상 목록을 간략히 보여줍니다. | 특정 영상 처리가 비정상적으로 길어지거나, 실패가 반복될 경우 원인을 파악하고 신속하게 대응할 수 있습니다. |

### 3.2. 콘텐츠 관리

서비스의 핵심 데이터인 영상과 댓글을 관리합니다.

#### 영상 관리

-   **기능**:
    -   지금까지 생성된 모든 영상의 목록을 상태(완료, 처리 중, 실패 등)와 함께 보여줍니다.
    -   영상 제목으로 특정 영상을 검색하거나, 상태별로 필터링할 수 있습니다.
    -   **삭제**: 문제가 있는 영상(저작권, 부적절한 콘텐츠 등)을 데이터베이스에서 영구적으로 삭제합니다. 관련된 대본과 댓글도 함께 삭제됩니다.
-   **사용자에게 미치는 영향**:
    -   **서비스 품질 유지**: 사용자에게 부적절하거나 품질이 낮은 콘텐츠가 노출되는 것을 방지합니다.
    -   **데이터 관리**: 오류가 발생했거나 불필요한 데이터를 정리하여 시스템을 쾌적하게 유지합니다.

#### 댓글 관리

-   **기능**:
    -   모든 영상에 달린 댓글을 최신순으로 보여줍니다.
    -   닉네임이나 댓글 내용으로 특정 댓글을 검색할 수 있습니다.
    -   **삭제**: 스팸, 욕설 등 커뮤니티 가이드라인에 어긋나는 댓글을 관리자 권한으로 즉시 삭제합니다.
-   **사용자에게 미치는 영향**:
    -   **건전한 커뮤니티 환경 조성**: 악성 댓글을 신속하게 제거하여 모든 사용자가 쾌적하게 서비스를 이용할 수 있는 환경을 만듭니다.

---

### 3.3. 비용 관리

서비스 운영의 핵심인 후원금과 API 비용을 투명하게 관리합니다.

#### 후원금 관리

-   **기능**:
    -   후원자명, 금액, 날짜, 메시지를 포함한 후원 내역을 직접 추가하고 관리합니다.
    -   후원자명이나 메시지 내용으로 특정 후원 내역을 검색할 수 있습니다.
-   **사용자에게 미치는 영향**:
    -   **서비스 지속성**: 후원금을 정확히 기록하고 관리하여 대시보드의 '재정 요약'에 정확하게 반영되도록 합니다. 이는 서비스가 얼마나 더 운영될 수 있는지를 결정하는 기반이 됩니다.

#### API 비용 내역

-   **기능**:
    -   각 영상 해설을 생성할 때마다 발생한 API 비용(토큰 사용량, 모델 종류, 비용)을 상세하게 보여줍니다.
    -   비용이 높은 순, 최신 순으로 정렬하거나 영상 제목으로 검색할 수 있습니다.
-   **사용자에게 미치는 영향**:
    -   **비용 최적화**: 비정상적으로 비용이 많이 발생하는 영상(지나치게 길거나, 프레임이 많은 영상)을 식별하는 데 사용됩니다. 이를 통해 향후 '영상 길이 제한'과 같은 정책을 수립하여 불필요한 비용 지출을 막고 서비스 운영 기간을 늘릴 수 있습니다.

---

### 3.4. 서비스 설정

코드 수정이나 재배포 없이 서비스의 주요 정책과 동작을 실시간으로 변경합니다. **이 설정들은 사용자 경험에 즉시 영향을 미치므로 가장 신중하게 다루어야 합니다.**

| 설정 항목 | 설명 | 사용자에게 미치는 영향 |
| :--- | :--- | :--- |
| **영상 길이 제한** | 해설을 생성할 수 있는 유튜브 영상의 최대 길이를 설정합니다. (예: 30분) | **직접적인 기능 제한**: 설정된 시간보다 긴 영상에 대해 사용자가 해설 생성을 요청하면, "비용 문제로 처리할 수 없다"는 메시지가 표시되고 생성이 차단됩니다. API 비용을 관리하는 가장 효과적인 수단입니다. |
| **신규 화면 해설 생성 중지** | 이 토글을 켜면, 모든 신규 영상의 해설 생성이 즉시 중단됩니다. | **서비스 일시 중단**: 후원금 소진, 긴급 서버 장애 등 위급 상황 시 이 기능을 사용합니다. 사용자들은 더 이상 새 영상 생성을 요청할 수 없으며, "관리자에 의해 생성이 중지되었다"는 안내를 받게 됩니다. 기존에 생성된 영상은 정상적으로 이용 가능합니다. |
| **환율 설정** | 대시보드에 표시되는 API 비용(USD)을 원화(KRW)로 환산할 때 사용할 환율을 지정합니다. | **정보의 정확성**: 관리자가 재정 현황을 더 정확하게 파악할 수 있도록 돕습니다. 사용자에게 직접적인 영향은 없으나, 운영 판단의 기준이 됩니다. |
| **공지사항 관리** | 제목과 내용을 입력하여 서비스 전체에 공지를 띄울 수 있습니다. | **중요 정보 전달**: 제목을 비워두면 공지가 표시되지 않습니다. 제목과 내용을 입력하고 저장하면, 모든 사용자가 서비스에 접속했을 때 **가장 먼저 공지사항 팝업**을 보게 됩니다. 긴급 점검, 운영 정책 변경 등 중요한 정보를 모든 사용자에게 확실하게 전달할 수 있습니다. |
