## 2. 상세 운영 지표

*   **TTS 사용 패턴:** TTS 호출(6,050건)이 영상 생성 건수(99건)에 비해 월등히 높습니다. 이는 사용자들이 새로운 영상을 계속 생성하기보다, **기존에 생성된 인기 영상들을 반복 청취하거나 공유된 링크를 통해 유입**되고 있음을 보여줍니다.

### 2.2 영상 처리 및 비용 효율
*   **비용 분석:**
    *   건당 평균 비용이 **$0.228**로 지난주 대비 약 10% 감소했습니다. 30분 제한 정책이 고비용 영상 생성을 효과적으로 억제하고 있는 것으로 판단됩니다.

*   **SSL Handshake 오류:**
