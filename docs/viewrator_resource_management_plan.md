# 뷰레이터(ViewRator) 동적 자원 관리 및 인증 시스템 설계안

이 문서는 한정된 후원금(API 및 운영 비용)을 효과적이고 공정하게 분배하기 위한 시스템의 목표, 정책 및 구현 계획을 기술합니다.

---

#### 1. 시스템 목표 (System Objectives)
*   **자원 보호:** 후원금으로 충당되는 API 비용(Gemini, TTS)을 악의적인 독점이나 낭비로부터 보호한다.
*   **공정 분배:** 실제 주인공인 시각장애인 사용자에게 자원을 집중하되, 신규 사용자에게도 충분한 체험 기회를 보장한다.
*   **효율 극대화:** "남는 자원이 없어야 한다"는 원칙에 따라, 예산 범위 내에서 최대한 많은 영상을 해설화한다.
*   **접근성 유지:** 인증 절차가 시각장애인 사용자에게 장벽이 되지 않도록 '보이지 않는 제어'를 지향한다.

#### 2. 자원 및 사용자 정의 (Definitions)
*   **사용량(Resource Metric):** 화면 해설 영상을 만드는 데 사용된 **원본 유튜브 영상의 길이(단위: 분)**를 기준으로 산정한다.
*   **사용자 분류:**
    1.  **게스트 (Guest):** 비회원 사용자. 체험 수준의 제한된 권한 부여.
    2.  **시각장애인 회원 (Verified Member):** 외부 기관 연동을 통해 인증된 핵심 사용자. 자원 사용의 우선권 부여.

#### 3. 자원 배분 및 우선순위 정책 (Allocation Policy)
전체 월간 가용 자원(분)을 다음과 같이 격리된 풀(Pool)로 관리한다.

| 구분 | 할당 비중 | 정책 및 혜택 | 우선순위 |
| :--- | :--- | :--- | :--- |
| **시각장애인 (기존)** | 70% | 동적 쿼타 적용, 개인 라이브러리 제공 | **최우선 (High)** |
| **시각장애인 (신규)** | 20% | **웰컴 포인트** 보장 (가입 첫 달 보호) | **우선 (Medium)** |
| **게스트** | 10% | 하루 1~2편(또는 특정 분) 제한, 인증 유도 | **일반 (Low)** |

#### 4. 동적 자원 관리 알고리즘 (Dynamic Engine)
특정 사용자의 독점 방지와 자원 소진 극대화를 위해 다음 정책을 시행한다.

*   **개인 사용량 조절 지표 (User Score):**
    *   **완주율:** 생성 요청한 영상을 실제로 시청했는가?
    *   **기여도:** 내가 만든 영상이 다른 사용자들에게 얼마나 공유/시청되었는가?
    *   **피드백:** 서비스 품질 개선 활동(댓글, 신고 등)에 참여했는가?
*   **독과점 방지 정책:**
    *   **누진적 가상 비용:** 특정 기간 내 과도한 사용 시 차감 포인트를 상향 조정(1.5배~3배).
    *   **가변 우선순위 큐:** 최근 사용량이 적은 사용자의 요청을 큐의 상단으로 자동 배치.
*   **잔여 자원 자동 개방 (Surplus Burst):**
    *   월말 기준 예산 연소율(Burn Rate)이 낮을 경우, 모든 회원의 일일 한도를 일시 해제하여 자원을 100% 소진함.

#### 5. 구현 선행 사항 및 로드맵 (Implementation Roadmap)

**[Phase 1: 인프라 구축]**
*   **외부 기관 인증 브릿지:** 타 기관(장애인 연합회 등) API 연동을 통한 초간편 인증 구현.
*   **정밀 사용량 트래커:** 영상 길이와 사용자 ID를 매핑하여 실시간으로 기록하는 로깅 시스템 구축.

**[Phase 2: 지능형 제어]**
*   **우선순위 기반 워커(Worker):** 요청자 등급 및 우선순위에 따라 처리 순서를 제어하는 백엔드 스케줄러 개편.
*   **실시간 예산 모니터:** (소진 분 / 목표 분)을 감시하여 시스템 전체의 제한 수위를 조절하는 데몬 구현.

**[Phase 3: 사용자 UX 최적화]**
*   **개인 맞춤형 대시보드:** 남은 사용량, 내가 기여한 영상 목록, 선호 설정 저장 기능 제공.
*   **게스트 전환 유도:** 게스트 제한 시 "인증 후 우선 처리" 안내 메시지 고도화.
