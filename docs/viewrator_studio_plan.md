# 뷰레이터 스튜디오 (ViewRator Studio) 기획안

## 1. 개요 (Overview)
**뷰레이터 스튜디오**는 전문 화면 해설 작가들이 고품질의 화면 해설 대본을 더 효율적이고 창의적으로 작성할 수 있도록 돕는 **AI 기반 화면 해설 저작 보조 도구(AD Authoring Co-pilot)**입니다. 

기존의 단순 자동 생성 방식에서 벗어나, 작가의 예술적 의도를 반영하고 기술적인 번거로움(타임스탬프, 구간 확인 등)을 AI가 대신 처리하는 인간-AI 협업 환경을 지향합니다.

---

## 2. 핵심 비전 (Vision)
- **"빈 화면의 공포 제거"**: AI가 생성한 초벌 대본(Draft)을 제공하여 작가의 시작을 돕습니다.
- **"기술에서 예술로"**: 작가는 타임스탬프 계산과 같은 반복 작업 대신, 장면의 정취를 담아내는 묘사와 문학적 표현에 집중합니다.
- **"지능형 오케스트레이션"**: 여러 AI 모델의 강점을 결합하고 작가의 의도를 정교하게 투영합니다.

---

## 3. 주요 기능 (Core Features)

### 3.1. 지능형 초벌 대본 생성 (AI Drafting)
- **장면 분석 기반 초안**: 영상의 시각적 흐름과 자막 데이터를 분석하여 1차 대본 자동 생성.
- **가이드라인 준수**: 화면 해설 표준 지침(KBU 등)을 기본적으로 준수하며 생성.

### 3.2. 작가 의도 반영 프롬프트 (Intent-Based Prompting)
- **디렉터스 노트(Director's Note)**: 작가가 특정 장면이나 전체 영상에 대해 원하는 톤앤매너, 강조 사항을 입력하면 이를 AI 프롬프트로 변환.
- **프롬프트 커스터마이징**: 특정 모델에 최적화된 프롬프트를 작가가 직접 튜닝하거나 저장된 프로필(액션, 드라마, 다큐 등)을 선택 가능.

### 3.3. 멀티 모델 교차 검증 및 머지 (Multi-Model Ensemble)
- **병렬 생성**: Gemini(시각 분석 강점), GPT-4o(문장 유려함 강점) 등 여러 모델에서 동시에 대본 생성.
- **교차 비교(Side-by-Side)**: 서로 다른 AI의 제안을 나란히 비교하며 최적의 표현 선택.
- **스마트 머지(Merge)**: 특정 모델의 타임라인과 다른 모델의 묘사를 결합하거나 작가가 좋은 부분만 골라 담는 인터페이스.

### 3.4. 타임라인 및 갭(Gap) 관리
- **Cue Point 추천**: 대사가 없는 '해설 가능 구간(Gap)'을 AI가 자동 탐지하여 작가에게 추천.
- **실시간 TTS 프리뷰**: 작성 중인 대본을 즉시 TTS로 출력하여 영상 대사와 겹치는지, 해설 속도가 적절한지 확인.
- **동적 볼륨 더킹(Ducking)**: 해설 재생 시 영상 볼륨이 자동으로 줄어드는 실제 청취 환경 시뮬레이션.

### 3.5. 전문 작가용 인터페이스 및 내보내기
- **전용 웹 에디터**: 영상 플레이어와 타임라인 기반 대본 편집창이 통합된 UI.
- **다양한 포맷 지원**: SRT, VTT는 물론 방송 표준 포맷(EBU-STL 등)으로 내보내기.

---

## 4. 기술 전략 (Technical Strategy)
- **Prompt Chaining**: Analyzer(분석) -> Describer(묘사) -> Synchronizer(싱크)의 3단계 파이프라인 고도화.
- **API 통합 레이어**: 여러 LLM API(OpenAI, Anthropic 등)를 쉽게 연동할 수 있는 추상화된 백엔드 구조.
- **데이터 구조화**: 편집과 재가공이 용이한 JSON 기반의 표준 데이터 스키마 정의.
