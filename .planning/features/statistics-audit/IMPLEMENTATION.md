## 구현

- 기존 단일 수집기를 import 가능한 `stats_core.js`와 CLI `stats_collector.js`로 분리했다. 원격에는 독립 함수를 전달하며 서비스 database.js를 import하거나 마이그레이션하지 않는다.
- 모든 현재 20개 테이블의 수집 범위와 스키마를 기록한다. 누락/새 테이블, 쿼리 실패, 원장 불일치, 파일 읽기 실패·미관측 날짜를 경고한다.
- 한국 시간의 반개방 날짜 범위를 UTC로 변환하고 SQL/ISO 날짜 및 epoch 영수증을 정규화한다. 최초 가입 이전은 실제 가입 순간으로 제한한다.
- 영상별 설명 비용을 사전 집계해 영상/길이 중복을 방지한다. Q&A 상세/일별 비용은 대조하며 중복 합산하지 않는다. 구형 토큰 구성은 미수집으로 표시한다.
- API 기능별 요청·회원·일별 이용, Q&A 영수증 상태, 비용/가격/검색, 현재 캐시/lease/참조 파일, 대본/격리/인증/후원금/허용 설정을 포함했다.
- gzip 포함 Nginx와 일별 백엔드 QA 이벤트를 스트리밍하고 운영 서비스 PM2·Nginx 오류 로그도 분석한다. API 상관 매칭은 IP별 정렬 시각과 이분 탐색을 사용하며 원시 IP·ID·오디오 티켓은 출력하지 않는다.
- `build_monthly_report.py`는 v2 JSON만 읽는다. 기존 8장 디자인을 유지하고 지표의 정확한 이름, 키보드로 여는 집계 근거, 설명 전용 비용 비율, 입력·수집기 SHA-256 manifest를 제공한다.
- 텍스트와 JSON은 동일 수집 결과에서 생성한다. 월간 helper는 항상 다시 수집한다. 공유 monthly-sponsor-report-deploy 스킬의 기존 실행 경로는 test 브랜치의 버전 관리 도구에 연결했다.

## TXT 가독성 개선

`stats_text.js`에 표시 형식을 분리했다. 핵심 요약, 한글 항목명과 상태, 정렬된 표, 숫자 구분·단위, 경고 설명, 로그·테이블 부록을 제공한다. 긴 비정상 요청 방식 문자열은 합계와 종류 수로 묶고 JSON에 원문을 보존한다. null은 확인 불가로 유지한다. 신규 수집기의 SHA-256에는 TXT 표시 모듈도 포함한다.

기존 8월 JSON으로 TXT만 재생성했다. JSON과 기존 HTML/PPTX 및 manifest는 변경하지 않았으므로 그 파일의 원자료 해시·수집 시각은 기존 수집 실행을 가리킨다. 다시 운영 자료를 수집하지 않았다. 기존 수집 fixture 4개와 주요 표시 값·미측정/0 구분·비정상 요청 합계·JSON 불변 검증을 통과했다.

## API 활성·재이용 및 상위 회원 집계

`stats_activity.js`를 추가해 수집 시점의 동일한 읽기 전용 DB 스냅샷에서 API 전체/핵심 기능 DAU·달력 주 WAU·최근 7일 WAU·달력 월 MAU, 기능별 일별 이용, 서로 다른 날의 반복 이용, 연속 주/월 재이용, 신규 가입자의 첫 핵심 이용 지연과 7일 재이용을 집계한다. 빈 날짜도 포함하고 관측 구간이 부족한 재이용률은 null로 둔다. 이전 달 기록은 최근 7일 WAU와 재이용 대조에만 사용하며 현재 기간의 회원·요청에 중복 합산하지 않는다. 실제 청취 기준 활성 회원과 API 기준 활성 회원을 분리했다.

상위 10명은 회원의 핵심 기능 API 요청 수로 선정하고 같은 요청 수이면 핵심 이용 일수로 정렬한다. 사용자 요청에 따라 내부 JSON/TXT에 이름·이메일과 기간 내 기능별 요청·이용 일수·등록 영상의 현재 상태·제목·링크를 포함한다. 원시 회원 ID·IP·비밀번호 등은 내보내지 않는다. 후원자 HTML/PPTX에는 개인 식별정보를 넣지 않는다. 영상별 API 경로 이용 목록은 JSON에 전체 보존하며 TXT에서는 회원 대본 조회 이용자 수 기준 상위 30개를 표시한다.

새 수집기로 8월 운영 자료를 다시 읽었다. 전체 API MAU 46명, 핵심 기능 MAU 43명, 일평균 DAU 5.16명/4.45명, 서로 다른 날에 핵심 기능 재이용한 회원 20명. 7월 로그가 월 전체를 덮지 않아 7월→8월 재이용률은 계산하지 않는다. 첫 핵심 이용 이후 7일을 관측한 신규 회원 11명 중 4명이 다른 날짜에 재이용했다. 상위 회원은 유승만이며 핵심 요청 5,759건·28일, 전체 API 요청 7,748건·29일, 등록 영상 87개(현재 완료 84개/실패 3개)다.

검증: 수집 fixture 7개 및 기존 후원자 builder fixture 3개 통과. 운영 DB의 별도 SQL로 일별 고유 회원, 전체/핵심 MAU, 핵심 요청 수, 반복 이용 회원 및 상위 10명 전원을 대조했다. 최종 수집기 4개 모듈의 SHA-256, JSON/TXT 동일 집계, 상위 10명 활동 합계, 후원자 HTML의 이메일 미포함을 확인했다. 기존 HTML/PPTX와 manifest도 새 JSON으로 재생성해 입력 해시를 동기화했다. DAU 시각화나 후원자 슬라이드 구성은 이번 통계 수집 변경에 포함하지 않았다.
