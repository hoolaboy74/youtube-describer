## 규칙 변경

1. 한국어를 아는 청취자가 외국어 원음도 이해한다고 가정하지 않는다.
2. foreign의 확인된 발화, mixed의 확인된 외국어 발화는 필수 trans이며 시각 해설보다 우선한다.
3. 발화의 주장·논거·조건·예시·수치·질문·답변을 선별 요약하지 않는다.
4. 누적 자동 자막의 표시 중복만 제거하고, 그 뒤에 추가되는 의미는 보존한다.
5. 모든 번역 대상을 확보한 뒤 필요한 시각 해설을 추가한다.
6. 원문 발화와 trans를 대조하여 누락을 자체 검수한다.
7. 한국어 재낭독 금지, 불확실한 언어 및 unknown 번역 금지, 시각 근거·출력 형식·시간 범위 규칙은 유지한다.

## 남은 문제

- 완전한 무누락 번역으로 인증할 수 없다. 예를 들어 경쟁사 열거의 입력에 있는 'Sonic' 표기가 새 번역에서도 '등'으로 압축된다. 원문의 ASR 표기 정확성도 별도 확인이 필요하다.
- 반 문장이 남는다. 24초 '흉내 냈고,' → 31초 후속 문장, 496초 '음질 비교가 아니며,' → 500초 후속 문장 등. 쉼표로 끝나는 trans는 기존 5줄, 변경 13줄이다. 이는 문장 완결성에 대한 보조 지표일 뿐 모든 부자연스러운 분절을 세는 것은 아니다.
- 첫 발화는 입력 start=0인데 새 출력은 1초다. 양수 시간 범위 검사는 통과하지만 임의 시각 이동 금지와 충돌한다. 프롬프트만으로 0초 발화 보존과 기존 양수 전용 계약을 동시에 해결하지 못했다.
- 긴 문장이 남아 실제 TTS에서 번역끼리 또는 시각 해설과 겹칠 수 있다. 실제 합성·재생으로 점검하지 않았다.
- txt에 영어 제목·라벨이 그대로 남는다(78초 등). 중요한 독립 외국어 글자의 한국어 의미 전달 규칙을 충분히 따르지 않았다.
- 시각 해설 정확성이 모두 개선됐다는 뜻은 아니다. 이번 평가는 번역 누락 복원에 초점을 두었고 원본 이미지 전체의 사실성 재검수는 수행하지 않았다.
- mixed 인터뷰의 정책은 추가했지만 이번 유료 실영상 실행은 foreign 한 편, 각 조건 한 번이다. mixed의 실제 동작과 반복 실행 안정성은 아직 검증하지 않았다.
- 치환 자리표시자/언어 경계 보존 확인 및 치환 후 assertV2PolicyPrompt 마커 검사를 통과했다. 이것은 의미적 무누락이나 canonical 재생 적격성 보증이 아니다.

## 결론

이 영어 설명 영상에서는 변경한 v13이 분명히 더 적합하다. 입력을 그대로 유지한 상태에서 이전에 빠진 의미가 대폭 복원되고 주변 화면 묘사가 줄었다. 프롬프트 우선순위가 원인 중 하나였다는 근거가 된다. 다만 번역 완전성 보장, 원문 시각 정렬, 자연스러운 문장 분할, 실제 TTS 재생 검증은 남아 있다.
