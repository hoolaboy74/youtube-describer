# 화면 해설 품질 실험 — 다음 대화의 시작점

2026-09-09 인계. GSD phase 진행은 중단한다. 기존 main의 Phase 1 구현을 되돌리는 작업은 아니다. 앞으로는 프롬프트와 모델 설정을 비교하여 시각장애인의 영상 이해·감상을 개선하는 데 집중한다.

## 작업 원칙

- test_scripts 안에서 실험하고 backend·DB·플레이어·운영 서버는 별도 요청 없이 변경하지 않는다.
- 프레임 관찰 나열보다 원음·번역으로 빠지는 대상·공간·변화·반응·비교 결과를 보완한다.
- 확인된 이름·필요한 독립 화면 글자는 전달한다. 감정은 보이는 표정·몸짓과 확인된 편집 글자로 전달하며 보이지 않는 의도·인과를 만들지 않는다.
- 외국어 영상 및 혼합 인터뷰의 확인된 외국어 발화는 trans가 해설보다 우선하며 의미를 빠뜨리지 않는다. 한국어 재낭독·불확실한 언어 번역은 금지한다.
- [정수초][txt] 자막 내용 형식을 유지한다. 출력·시간·안전·번역 규칙과 새 지침이 충돌하면 사용자에게 먼저 묻는다.
- 생성 결과는 원문 그대로 보존한다. 통과 항목 수나 짧은 대본을 품질 점수로 쓰지 않는다.

## 권장 다음 작업

현재 v13로 가족·외국어 영상 각각을 이전 동일 모델 결과와 비교한다. 추가 호출에는 비용이 발생한다. 가능하면 조건별 반복 실행으로 우연한 차이를 구분한다. 혼합 인터뷰에서 외국어 번역 우선 정책도 별도 검증한다.

모델 원문뿐 아니라 backend 검증 후 실제 재생될 내용과 제외 사유를 함께 평가한다. 현재 비교 스크립트에는 생성 후 canonical 검증 결과 저장 기능이 없으며, 이를 이미 구현했다고 가정하지 않는다.

main worktree의 test_scripts를 이후 실험의 기준 위치로 사용한다. test 쪽 복사본은 인계 시점 보존본이다. 과거 JSON의 절대 경로는 실행 당시 경로이므로 새 worktree의 상대 result 경로로 찾아 읽는다.
