# v13 맥락 중심 화면 해설 지침 보강

## 변경 범위

- 대상: prompt_template_writer_v13.txt (번역 우선 규칙이 적용된 버전).
- 백업: prompt_template_writer_v13_before_context_guidance.txt.
- 기존 문장을 수정·삭제하지 않고 세 절을 추가했다.
  - 전체 맥락을 위한 집필 기준
  - 맥락에서 세부로: 청취자의 이해를 갱신하는 문장
  - 맥락 이해 검수
- backend 프롬프트, API 코드, 자막 전처리, DB, 플레이어는 변경하지 않았다.

## 근거와 서비스에 맞춘 적용

### DCMP Description Key

원문: https://dcmp.org/descriptionkey/print

참조 절: Quality Description / Preparation / What to Describe — General.

DCMP는 작품을 충분히 이해하고, 학습·이해·감상에 중요한 시각 정보를 선별하며, 맥락을 먼저 세운 뒤 세부를 보태도록 권한다.

이를 우리 입력 조건에 맞춰 '한국어 대사·필수 번역으로 알 수 있는 내용'과 '시각 정보가 없으면 불명확한 내용'을 먼저 구분하는 내부 작업으로 적용했다. 실제 원음을 듣지 않는 모델이 소리·침묵을 추정하지 않도록 기존 경계를 명시했다.

### Netflix Audio Description Style Guide v2.5

원문: https://partnerhelp.netflixstudios.com/hc/en-us/articles/215510667-Audio-Description-Style-Guide-v2-5

참조 절: Goal / 1.1 The Basics / 1.2 Describing Actions.

Netflix는 이해·감상에 필요한 인물과 행동을 우선하고, 불필요한 과잉 묘사를 피하며, 말과 다른 표정·반응과 의미 있는 시각적 표현을 전달하도록 안내한다.

이를 '보이는 물체가 무엇인가'에서 멈추지 않고, '그 정보가 현재 대상·배치·변화·반응을 어떻게 이해하게 하는가'를 점검하는 절차로 구체화했다. 단, 제작 의도나 인물 내면을 추론하는 허가로 확장하지 않았다.

## 추가 지침의 핵심

1. 전체 영상을 파악한 뒤 내부 집필 방향을 정하지만, 그 방향을 요약 해설로 출력하지 않는다.
2. 청취자가 이미 아는 대상·장소·상태에서 새로 갱신해야 하는 정보를 고른다.
3. 관찰 항목 수를 늘리는 대신 필요한 대상과 배치·차이·반응을 정확히 표현한다.
4. 삽입 자료와 실제 현장의 사건을 혼동시키지 않는다.
5. 대사·번역·해설을 합쳐 이해가 이어지는지 검수한다. 해설만으로 완결된 이야기를 만들려 하지 않는다.
6. 맥락 중심은 줄거리 외의 미적·정서적 시각 정보를 전부 삭제한다는 뜻이 아니다.

## 기존 규칙과의 경계

- 번역을 요약하거나 누락시키는 근거로 새 지침을 사용할 수 없다.
- 기존의 사실 근거, 추측 금지, 한국어 원음 중복 금지, txt 표현, 태그, 시간, 길이 규칙을 변경하지 않았다.
- 외부 가이드의 대사 중첩 제한, 사전 해설·타이밍 운용, 로고 처리 등 다른 지침은 이번 보강에 도입하지 않았다. 향후 도입할 경우 기존 정책과 비교하고 충돌은 사용자에게 먼저 확인해야 한다.
- 기존 0초 발화와 양수 타임스탬프 계약의 문제도 이번 작업에서는 변경하지 않았다.

## 검증

- 추가한 세 절을 제거하면 수정 전 원문과 바이트 단위로 동일함을 확인했다.
- 정확성·인물 표현, 화면 글자·중복 금지, 언어별 번역, 출력·시간, 입력 데이터 절이 그대로임을 확인했다.
- 자리표시자 치환 후 assertV2PolicyPrompt 검사를 통과했다.
- 실영상 모델 생성은 이번 변경 후 실행하지 않았다. 이 문서는 지침 변경과 보존 검증의 기록이며, 생성 품질 개선을 입증한 A/B 결과는 아니다.
